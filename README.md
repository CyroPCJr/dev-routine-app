# DevRoutine

DevRoutine is a study planner and habit tracker designed for developers who want to organize their learning routine, personal projects, technical goals, and daily execution.

## Features

- Daily developer planner
- Study habit tracking
- Personal project progress
- Weekly productivity overview
- Premium templates and advanced statistics

## Tech Stack

- Flutter
- Dart
- Material 3
- Clean Architecture
- MVVM
- Firebase Auth
- Firestore
- RevenueCat / Google Play Billing

## Project Status

MVP in development.

## Architecture

This project follows a simplified Clean Architecture approach with feature-based modules.
